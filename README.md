# Linear-Regression-Sales-Prediction

## Project Description

This project builds a Linear Regression model using a simple dataset to predict sales based on advertising spend.

## Objectives

- Understand Linear Regression
- Prepare the dataset
- Train a Linear Regression model
- Make predictions
- Evaluate the model
- Visualize the relationship between advertising spend and sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Model

Linear Regression

## Skills

- Regression analysis
- Data preparation
- Machine Learning
- Data visualization
- Model evaluation

## Project Outcome

The project demonstrates how Linear Regression can be used to predict sales from advertising-related data.
